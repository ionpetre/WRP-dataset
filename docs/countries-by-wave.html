How common were the clusters in each survey?

Select a cluster to compare its share in the same 92 countries. The cluster definition stays the same throughout.

How we hold the definitions fixed

We apply one fitted definition, from 2025, to the answers in each survey. The bars average country shares with equal country weights. Each survey interviewed different people, so the changes describe population frequencies.
