World Risk Poll · 2019–2025

Methods and data

The Atlas separates the clusters selected in each wave from changes measured under one fixed 2025 definition.

Each wave has its own selected model

The full models use six worries and all fourteen harm indicators. Worry-only models use five common worries, allowing 2019 to be included. The 2025 full model is the primary benchmark. Earlier frozen models remain unchanged.

Personal harm concerns the respondent; known-person harm concerns someone personally known. Both indicators equal 1 when both experienced harm.

Countries have equal total influence, preserving relative survey weights within each eligible country. These are not world-population proportions. Missing or special answers are not interpreted as no worry or no harm.

Two different comparisons

Cluster shares: hold the 2025 model fixed

Apply the original frozen 2025 transformation and centres to each wave’s own respondents. Calculate survey-weighted country shares, then average over the same countries: 92 for full worry–harm and 90 for worry only. Changes are percentage-point differences. The respondents differ across waves, so these are not individual transitions.

Cluster definitions: hold the reference answers fixed

Assign the same observed 2025 answers using both original frozen models. The overlap table shows how each earlier cluster is distributed across the 2025 clusters. It uses country/survey weights, and each unrounded row sums to 100%.

The models retain their original fitting populations. Their reference answers come from 90,395 respondents in 92 countries for full worry–harm, or 91,249 in 90 countries for worry only. Each model applies its own coding and centres.

How much difference comes from fitting variation?

A separate experiment refits each wave’s selected settings on the same common-country frame. It uses 100 respondent subsamples, 100 country subsamples and 20 initialization-only runs per model: 1,540 fits. The site shows the country-subsampling comparison.

Every run assigns the same reference respondents. Within-wave ARI uses all 4,950 distinct run pairs; cross-wave ARI uses all 10,000 combinations. Dots show median ARI, with 10th–90th percentile ranges. The pairs share fitted models and are dependent. The ranges describe fitting variation; they are not confidence intervals or a repeat of the full selection procedure.

ARI uses respondent counts and permits different cluster counts. It is not a survey-weighted percentage agreement. The overlap table uses country/survey weights. Finer selected partitions can disagree even when coarser alternatives agree closely: independently selected three-cluster full alternatives for 2021 and 2025 give ARI 0.963 in the matched-country comparison. These alternatives do not replace the four- and six-cluster benchmarks.

Detailed 2023 results

The original WARM-5 explorer, country comparisons and income analyses retain their 2023 scope, original assignments and distance calculations. They are separate from the new all-wave comparisons. Their historical display numbers 1–5 correspond to stored T5 IDs C0–C4.
