How these profiles were built and checked

Held-out respondents were assigned to the frozen development centres. No held-out model was fitted. Similar aggregate descriptions support transfer, but do not establish identical country-specific meanings or universal social types.

Only complete responses to all six worry and seven harm-domain questions were eligible. Missing responses were not imputed. The development set contains 109,488 eligible respondents in 113 countries; the held-out set contains 27,972 in 29 countries. Excluded respondents may differ systematically.

Profile names are descriptive summaries. A profile can be strongly associated with one survey response without being reducible to a single rule. Stability of the whole partition does not guarantee that every individual profile is equally stable.
