# Response profiles and country comparisons

Open `index.html` for the response profiles, `countries.html` for country comparisons or `country-income.html` for income patterns. All three pages are self-contained and work offline, with aggregate information only. Navigation lists the profiles first, then country comparisons and income patterns.

GitHub Pages publishes `docs/` as the website root. Supporting Markdown and CSV files outside that folder therefore link directly to their GitHub repository pages, not to `../research/` or `../course_artifacts/` on the website. These supporting-file links require internet access; the embedded profile and map interactions do not. `.week05_build/test_research_page_links.py` checks links against the published project root as well as local files.

The profile explorer starts with the four-profile solution and also shows the eight-profile solution. Profile cards show equal-country-weighted development shares. Selecting a card displays the three frozen descriptive anchors, full worry-category distributions and separate personal/known-person harm prevalences, compared with respondents outside that profile. The overview matrices show percent very worried or harmed; the detailed bars retain all worry categories. Overlap rows are conditional percentages of each four-profile group assigned to each eight-profile group, not a hierarchical subdivision. Source marginals are checked against the frozen profile shares. Display numbering starts at 1; stored identifiers remain unchanged at 0. The expandable evidence section reports pairwise stability and selected-profile held-out mismatch, with the weaker individual-profile recovery of the eight-profile solution explicitly noted. No fits or respondent records are used to generate the explorer. Regenerate with `.week05_build/export_response_profiles.py` or the common map exporter.

The default **Original response distributions** compares worry-category distributions and separate personal/known-person harm prevalence. **Worry and harm equally weighted** gives worry and total harm half the weight each (research model B). **Worry given greater weight** gives worry three times the weight of total harm (research model E). Personal and known-person harm share the harm weight equally in both comparisons. The webpage uses these descriptions rather than model letters or numerical shorthand. **Frozen profile mixtures (Hellinger)** preserves historical four-profile and eight-profile comparisons. **Overview** is an approximate two-dimensional view available only for profile mixtures. Original dataset-region outlines remain unchanged.

Distances are expressed relative to a fixed all-country median. Overall B/E views share the median of their pooled distinct-pair distances, **0.1550977480973838**; each component uses its own median. **1 means the typical reference distance; 2 means twice that distance.** Seven fixed equal-width colour bands span 0–2, with the endpoint labelled **2 or more**. Numerical labels are uncapped. This plotting ceiling is not a scientific threshold. The same pair retains its value and colour across selections and development-only/full views. B/E colours are directly comparable; component colours compare fractions of different component medians, not equal raw gaps. Historical Hellinger uses its own shared B4/E8 median. Ratios are not percentages of societal similarity.

Lists show 10, 20 or all peers, ranked by unrounded distance. Metric names are written in full: **Median-relative total variation distance** or **Median-relative Hellinger distance**. Lists and tooltips show ratios, without raw-distance or percentile clutter. Worry mismatch is mean feature total variation ×100; harm gaps are mean absolute prevalence differences in percentage points. The main map ranks the selected component. The income page's lists and mean median-relative matrices always use overall B/E allocations; component selection changes the map only. Family selection changes all comparisons together. There is no scale selector.

These maps describe selected responses, not societal equivalence or a new country typology. No profile models were refitted. Equal response marginals can hide different within-person combinations; exact ranks are descriptive, without newly computed rank uncertainty.
