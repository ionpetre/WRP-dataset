# Reproducing the paper

Use the single notebook in `../paper/`. It includes all analytical code, saved results, aggregate verification and optional fitting. Run All starts no scientific fitting. The complete candidate catalogue is retained, including the historical adaptive proposals. Older prediction code is archived supplementary work.

See [the complete companion](../paper/README.md), [current overview](../docs/index.html), [methods](../docs/methods.html) and [archive guide](../archive/README.md). The exact model definitions, fitting scope, populations, equations and aggregate inputs are documented together in the companion.
