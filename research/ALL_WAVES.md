# All-wave clustering

The principal full-model set has seven clusters in 2021, 2023 and 2025; four components have stronger conditional cross-wave recovery. The later-wave five-worry set has identical three-way point assignments. No equally robust shared classification was found including 2019. All 47 passing settings and 259 rules remain available as alternatives.

See [the complete companion](../paper/README.md), [current overview](../docs/index.html), [methods](../docs/methods.html) and [archive guide](../archive/README.md). The exact model definitions, fitting scope, populations, equations and aggregate inputs are documented together in the companion.
